## El historial de git: donde está el debate

**El repositorio no se construyó de una vez.** **Cada commit es una decisión fechada, y su mensaje dice qué se cambió y por qué.** **Ese es el rastro que el resto del trabajo sostiene.**

```bash
git log --oneline
git show <commit>      # el cambio completo, con su mensaje
```

**Y el rastro no es decorativo:** **cada commit está firmado y verificado con una llave GPG.** **Si alguien quisiera rehacer la historia, se nota.**

## Lo que este mapa no hace, a propósito

- **No resume los ensayos.** **Un resumen se lee en vez del ensayo**, y **ese es exactamente el error que el repositorio previene.**
- **No dice cuál es la conclusión.** **Cada lector arma la suya**, y la de este autor es una de muchas.
- **No copia pedazos del repositorio anterior.** Se apunta, no se copia.
