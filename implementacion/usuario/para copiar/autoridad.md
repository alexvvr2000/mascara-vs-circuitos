# autoridad

**Quién decide lo que el ente no decide.** **Un solo nombre, y una persona.**

| El campo | Qué va ahí | El valor |
|---|---|---|
| **el nombre** | quien firma | |
| **lo que no decide el ente** | lo que nunca se decide sin esta persona | |
| **cómo se le pregunta** | cómo se le avisa, y cuánto puede tardar | |

---

**Y la regla que hace que esto sirva:** **el ente propone, y esta persona cierra.** **Mientras no conteste, lo propuesto sigue abierto, y así se dice.**

**Falsificador:** una autoridad que no contesta nunca, y un ente que se cierra solo por no esperar.
