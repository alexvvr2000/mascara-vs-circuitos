# El stack, del autor

**La tabla que declara con qué se levanta el ente.** **Se llena a mano, y se cambia cuando un ensayo lo pida.**

**No es una configuración: nadie la lee con un programa.**

---

## La tabla

| El campo | Qué va ahí | El valor |
|---|---|---|
| **el ente** | un nombre corto | |
| **el dueño** | quién decide, con nombre | |
| **el motor** | dónde vive el ente | `DeepSeek Harness` |
| **el catálogo** | de dónde salen las piezas | `dshmarket` |
| **la base** | dónde vive el criterio | `graphdblite` |
| **el cuerpo** | qué modelo piensa | |
| **el sesgo del cuerpo** | lo que hace mal ese modelo | |
| **la autoridad** | quién firma | |
| **lo que la autoridad no decide** | lo que el ente no decide nunca | |

**Y una sola cosa no se elige por gusto, porque es la única que no lo es:** **la base va en un grafo.** **El índice tiene tres relaciones —contiene, asocia, supera— y la consulta que más se va a hacer es por dónde se llega de un tema a otro.** **En una tabla de renglones eso es un recorrido escrito a mano; en un grafo es una arista.**

---

## Falsificador

**Un stack llenado con lo que suena bien y nunca usado.** **La señal, en el acto:** **la tabla está completa y no hay un solo hecho en el registro.**
