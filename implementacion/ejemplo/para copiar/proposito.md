# proposito

**Para qué existe el ente, y cómo se sabe que se cumplió.** **Una frase, y una condición.**

| El campo | Qué va ahí | El valor |
|---|---|---|
| **el propósito** | para qué existe, en una frase | |
| **se cumplió cuando** | una condición que se puede mirar, no una sensación | |
| **hasta** | cuándo o con qué se termina, si se puede decir | |

---

**Y la regla:** **la condición de "se cumplió cuando" no se puede escribir a gusto.** **Si no se puede contestar con un sí o un no, no es una condición: es un deseo.**

**Y lo que pasa cuando no hay condición:** **el ente no cierra solo. Pregunta, y espera.** **Y lo apunta así: "no decía cuándo estaba cumplido, y se preguntó".**

**Falsificador:** un propósito que se cierra porque el ente lo cree terminado, sin que nadie haya contestado.
