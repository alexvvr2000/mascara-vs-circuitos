# `implementacion/`

**Dos carpetas que se copian a un proyecto.** **Ninguna se instala.**

---

## Las dos

| La carpeta | Qué trae | Para quién |
|---|---|---|
| **`ejemplo/`** | **el ente, con un stack ya probado. se copia y se usa** | **quien viene por un stack probado, y quiere trabajar ya** |
| **`usuario/`** | **el manual: cómo tomar ese ente y hacer el tuyo, con tu propio stack** | **quien viene a hacer el suyo desde cero** |

**Y son dos caminos distintos de entrada, no dos versiones de lo mismo.**

```plaintext
vienes por un stack probado    ->  ejemplo/
vienes a hacer el tuyo          ->  usuario/
```

**Y las dos cosas se pueden hacer a la vez:** **se copia `ejemplo/` para empezar rápido, y se lee `usuario/` cuando se quiera cambiar una pieza.**

---

## Cómo se usa

**1.** Se elige una de las dos.

**2.** Se copia entera al proyecto donde se va a trabajar.

**3.** Y se trabaja.

**Nada más.** **No hay nada que instalar, ni qué registrar, ni qué configurar en ningún lado.**

---

## Y las cuatro salidas

**Cualquiera que llegue al repositorio termina con una de estas cuatro, y las cuatro están previstas.**

**1 · No darle importancia y seguir con su vida.** **Se cierra y no pasa nada.**

**2 · Llevarse una de las dos carpetas.** **Se copia, se modifica, y se usa — incluso si no es para mejorar este repositorio.**

**3 · Mejorar el repositorio sin el autor.** **Con la versión propia, y citando este trabajo como punto de partida.**

**4 · Clonar el repositorio y sacar algo propio de él.** **Sin tocar estas carpetas, y sin esperar a que esto se termine.**

**Y la cuarta no se termina: se está en ella.**

---

## Y esto es comunidad

**El repositorio es el padre, y la gente clona el suyo.** **Unos se llevan una versión, otros empiezan de cero con la plantilla, y otros toman el repositorio entero y hacen su stack.**

**Y lo que hace que eso funcione es que las dos carpetas se puedan copiar y usar sin preguntar nada.**

---

## Hasta dónde llegan

**Lo que se copia es texto: la hoja de reglas, las piezas, el índice y la habilidad.** **El ente trabaja con eso, porque lo que necesita es una carpeta y un registro.**

**Y lo que no traen es código propio.** **No hay scripts de este repositorio, y no hace falta: los comandos son los del stack que se elija, y el ente los corre.** **Un script propio sería una dependencia más que copiar, y el punto es arrastrar una carpeta.**

---

## Falsificador

**Dos carpetas que se presentan como un camino y no llevan a ningún lado.** **La señal, en el acto:** **alguien las abre, y no puede empezar sin preguntar.**
