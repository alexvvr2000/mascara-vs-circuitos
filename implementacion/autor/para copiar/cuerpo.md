# cuerpo

**Qué modelo piensa, y qué se sabe que hace mal.** **Se declara, no se adivina.**

| El campo | Qué va ahí | El valor |
|---|---|---|
| **el modelo** | el nombre, y la vía | |
| **lo que hace mal** | lo que se sabe que este cuerpo falla | |
| **desde cuándo** | la fecha en que se empezó a usar | |

---

**Y por qué esto es opcional y no un adorno:** **sin cuerpo declarado, el ente trabaja igual, y sus hechos no dicen con qué se hicieron.** **El registro queda sin una de sus columnas.**

**Y si mañana cambia el cuerpo, no se reescribe lo de antes.** **Los hechos viejos se quedan con el cuerpo que tenían.**

**Falsificador:** un ente que deduce en qué modelo está, o que rellena hacia atrás los hechos que quedaron sin cuerpo.
